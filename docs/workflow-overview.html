Acc Documents — ผัง Workflow การทำงานจริงของระบบ

ระบบเอกสารเบิกจ่ายออนไลน์ของ Globe Syndicate: พนักงานกรอกฟอร์มเบิก ระบบออกเลขที่และคำนวณยอด ส่งให้หัวหน้า/ผู้อนุมัติเซ็นออนไลน์ หรือพิมพ์ไปเซ็นด้วยปากกา และฝ่ายบัญชีดูเอกสารทุกฉบับ

ใครใช้งาน

พนักงานผู้ใช้ทั่วไป — เห็นเฉพาะฟอร์มของกลุ่มตนเอง และเอกสารของตนเอง
หัวหน้า / ผู้อนุมัติไม่ใช่สิทธิ์แยก — คือพนักงานคนใดก็ได้ที่เจ้าของเอกสารเลือกให้เซ็นในช่องลายเซ็น จึงเห็นเอกสารนั้นได้
ฝ่ายบัญชี (Account Admin)เห็นเอกสารทุกฉบับ ตั้งค่าฟอร์ม จัดการพนักงาน ยกเลิก/ลบเอกสาร ตอบเรื่องแจ้งปัญหา
IT (Super Admin)ทำได้ทุกอย่างของฝ่ายบัญชี + เปลี่ยนชื่อผู้ใช้ และแก้บัญชี Super Admin
วิธีอ่านผัง จุดเริ่ม จุดจบ ขั้นตอน จุดตัดสินใจ ยังไม่เปิดใช้งาน
