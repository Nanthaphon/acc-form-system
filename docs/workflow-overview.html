Acc Documents — ผัง Workflow การทำงานจริงของระบบ

ระบบเอกสารเบิกจ่ายออนไลน์ของ Globe Syndicate: พนักงานกรอกฟอร์มเบิก ระบบออกเลขที่และคำนวณยอด ส่งให้หัวหน้า/ผู้อนุมัติเซ็นออนไลน์ หรือพิมพ์ไปเซ็นด้วยปากกา และฝ่ายบัญชีดูเอกสารทุกฉบับ — อ่านจากโค้ดในโปรเจกต์ ณ 11/11/2026

ใครใช้งาน (บทบาทที่มีจริงในโค้ด)

พนักงานผู้ใช้ทั่วไป (role = employee) — เห็นเฉพาะฟอร์มของกลุ่มตนเอง และเอกสารของตนเอง
หัวหน้า / ผู้อนุมัติไม่ใช่สิทธิ์แยก — คือพนักงานคนใดก็ได้ที่เจ้าของเอกสารเลือกให้เซ็นในช่องลายเซ็น จึงเห็นเอกสารนั้นได้
ฝ่ายบัญชี (Account Admin)role = admin — เห็นเอกสารทุกฉบับ ตั้งค่าฟอร์ม จัดการพนักงาน ยกเลิก/ลบเอกสาร ตอบเรื่องแจ้งปัญหา
IT (Super Admin)admin ที่ติด isSuperAdmin — ทำได้ทุกอย่างของ admin + เปลี่ยนชื่อผู้ใช้ และแก้บัญชี Super Admin

งานหลักของระบบ

  • ผัง 1 เพิ่มพนักงานและเข้าสู่ระบบครั้งแรก
  • ผัง 2 กรอก บันทึก และพิมพ์เอกสารเบิก
  • ผัง 3 ส่งเซ็นและอนุมัติออนไลน์
  • ผัง 4 แก้ไข คัดลอก และยกเลิกเอกสาร
  • ผัง 5 แจ้งปัญหาถึงผู้ดูแลระบบ

วิธีอ่านผัง

จุดเริ่ม จุดจบ ขั้นตอน จุดตัดสินใจ มีในโค้ด แต่ยังไม่เปิดในระบบจริง เลขอ้างอิงไฟล์/บรรทัด ใต้ผัง

สิ่งที่ยืนยันจากโค้ด กับสิ่งที่ต้องถามเพิ่ม

  • ยืนยันจากโค้ด — ทุกกล่องในผังมีเลขอ้างอิงไปยังไฟล์และบรรทัดที่ทำสิ่งนั้น
  • ต้องถามเพิ่ม — อยู่ในกรอบสีชมพูใต้แต่ละผัง เป็นเรื่องที่โค้ดตอบไม่ได้ หรือพฤติกรรมที่อาจไม่ตรงกับที่ตั้งใจ
  • ตรวจระบบจริงแล้ว (11/11/2026): แจ้งเตือนอีเมล ยังไม่ได้ deploy ฟังก์ชัน และ ยกเลิกเอกสาร ยังไม่ได้รัน SQL — แสดงเป็นกรอบเส้นประ
